Mol3D Viewer for Obsidian

Mol3D Viewer 是一款专为 Obsidian 深度定制的高性能 3D 分子可视化插件。它集成并优化了高性能的 3Dmol.js 渲染引擎，旨在打破传统笔记与科学数据之间的壁垒，使用户能够直接在 Obsidian 笔记环境中对复杂的化学分子、蛋白质大分子进行流畅的渲染、交互与分析。

无论是进行生物化学研究、日常教学演示，还是撰写学术笔记，Mol3D Viewer 都能为你提供近乎原生应用的沉浸式分子结构查看体验。

核心特性

全格式兼容性

插件提供对多种化学数据格式的原生解析支持，确保了科研工作流的无缝衔接：

.xyz：通用的笛卡尔坐标格式，适用于小型分子。

.pdb：蛋白质数据库标准格式，完整支持生物大分子的残基信息。

.sdf / .mol2：结构数据文件，保留化学键结信息与性质描述。

.cif：晶体学信息文件，支持复杂晶体结构的渲染。

工业级渲染模式

针对不同的科研需求，提供四种经过优化的渲染逻辑：

Stick (棒状)：强调化学键的几何分布，清晰展示原子间的连接关系与键角，是研究分子构效关系的理想选择。

Sphere (球状)：基于原子范德华半径的经典 CPK 填充模型，直观呈现分子的空间占位与位阻效应。

Line (线状)：极度精简的骨架展示，能够有效降低视觉负担，在大规模分子系统或初步筛选时提供流畅的性能表现。

Cartoon (卡通/光谱色)：专为结构生物学设计，通过光谱颜色梯度与丝带模型展示蛋白质的 alpha 螺旋、beta 折叠等二级结构构象。

多维度的嵌入机制

插件提供了三种灵活的展示方式，满足不同笔记排版需求：

代码块模式：支持直接在 Markdown 源码中粘贴分子坐标数据，或通过内部链接引用库内文件。

行内渲染 (Inline Mode)：首创通过双链语法实现行内微型模型嵌入，使 3D 模型可以像特殊字符或图标一样自然融入文本行中，极大地丰富了笔记的视觉表达力。

独立原生视图：插件会自动关联受支持的扩展名，支持直接双击文件打开全屏查看器。全屏模式下不仅提供 3D 渲染，还实时显示底层的文本数据流。

安全性与响应式设计

隐私第一：所有 3D 渲染过程均在用户本地设备上完成。插件不依赖任何外部云端渲染接口，不进行任何网络请求，确保敏感科研数据的绝对安全与隐私。

深度主题适配：完美兼容 Obsidian 的深色模式与浅色模式。支持背景透明化，使 3D 模型窗口能完美融入笔记的背景色中。

移动端优化：针对触摸屏操作进行了深度优化，支持通过手势进行旋转、缩放与平移，在平板设备上也能获得极佳的操作感。

安装方法

社区插件（推荐）

这是最便捷的安装方式，可获得自动更新支持：

打开 Obsidian 的 Settings -> Community plugins。

确保已关闭安全模式（Restricted mode）。

点击 Browse，在搜索框输入 "Mol3D Viewer Mobile"。

找到插件后点击 Install，安装完成后点击 Enable 激活。

手动安装 (Manual Installation)

如果你需要测试特定开发分支或在受限环境下使用：

前往 GitHub 的 Releases 页面下载最新的发布包。

在你的 Obsidian 库目录下，进入 .obsidian/plugins/ 文件夹。

创建一个名为 obsidian-mol3d-viewer-mobile 的新文件夹。

将 main.js, manifest.json, styles.css 以及核心依赖文件 3Dmol-min.js 悉数放入该文件夹。

在 Obsidian 插件面板中点击刷新按钮并启用。

全局设置选项

进入 Settings -> Mol3D Viewer 调整全局偏好：

布局预设：设置全局默认的块级窗口尺寸（通常设为 100% 宽度以便适配不同屏幕）。

边框自定义：统一笔记中所有分子模型的边框风格，保持视觉语言的一致性。

透明度偏好：如果你喜欢简洁的排版，可以全局开启“背景透明”，使分子直接浮动在笔记纸面上。

格式驱动设置：这是最强大的功能之一。你可以指定“只要是 .cif 文件，就默认用 Line 渲染”，而“所有 .pdb 文件默认用 Cartoon 渲染”。

开发者与故障排查

常见问题

模型无法显示？：请检查库中是否正确放置了 3Dmol-min.js。由于 3Dmol 库较大，它是作为独立文件加载的。

嵌入显示空白？：请确保文件名与双链引用的名称完全一致，且文件后缀在受支持的列表内。

性能优化：对于超过 10,000 个原子的复杂系统，建议在元数据中将 Style 设置为 line。

核心架构

本项目逻辑高度集成于 main.js：

Mol3DViewerMobile 类：负责 Obsidian API 的挂载、设置管理及 CSS 注入。

renderMolecule 函数：负责生命周期管理，包括数据拉取、3Dmol 实例初始化及 ResizeObserver 监听。

parseKeywords：负责从代码块源码中提取 Frontmatter 信息。
